# Provenance

`totp-batch` is an independent implementation based on RFC 4226 and RFC 6238,
their public test vectors, a supplied behavioral contract, and synthetic fixtures.
No competitor source code was copied.

No OneDrive or `nauth` tree was accessed. Source uses only Python standard-library
runtime facilities and declares no runtime dependencies.

## Publication boundary

Target is source publication at <https://github.com/otrumb/totp-batch>. No PyPI
upload, package publication, tag, or release is authorized or claimed.
